# iOS App (SwiftUI, iOS 17+)

Planned modules:
- Onboarding (guest + Sign in with Apple)
- Home (create/join/my events/friends)
- Event flow (markets, odds, lock countdown, chat, results)
- Creator/admin controls (results entry, moderation, settlement)

A full Swift project can be initialized in this directory and connected to Firebase using this repository's schema and function contracts.
